# ASSEMBLER

# Overview

This project is a RISC assembler + simultor implemented in Python by (Adwait Verma , Jagjot , Kunal , Vatsal). The assembler translates assembly language code for a simplified RISC architecture into machine code that can be executed on a corresponding processor.

# Feature

Instruction Set: Supports a subset of instructions for the RISC architecture.
Assembler: Converts assembly code (.asm files) into machine code (.bin files).
Output: Generates binary files that can be loaded and executed on a RISC processor simulator.
